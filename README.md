# Photonic Studio

A premium, responsive photography studio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — website structure and content
- `style.css` — complete responsive styling and animations
- `script.js` — navigation, loader and scroll animations

## Before publishing
Replace:
- phone number `+91 99999 99999`
- email `hello@photonicstudio.in`
- WhatsApp number in the `wa.me` link
- Instagram/Facebook links
- Unsplash demo images with your own licensed photography

## GitHub Pages
Upload the three files to your repository root and enable GitHub Pages from Settings → Pages → Deploy from branch → main → /(root).
